京东 · 淘宝 · 抖音

把心仪商品，安排在准点

京东支持从购物车选品或粘贴商品链接抢购；淘宝、抖音接入状态见下方。

当前空闲

同一时段支持一个购物车任务和一个详情页任务同时抢购，各自结算，不合并商品。选择「全部启用任务」统一启动；同一路径有多个任务时，请错开预热与购买窗口，否则启动前提示冲突。同一商品仍有跨入口防重，结果待核实时不重复下单。

提交前需要密码时自动填写；启用自动付款后也用于付款验证，未启用时关闭提交后的密码框并核实待付款订单。不保存到配置或日志，重新启动需再次输入，演练不填密码。

京东使用的浏览器

复用模式：在当前 Chrome 打开 chrome://inspect/#remote-debugging，开启允许远程调试；检测连接时在 Chrome 授权。然后在同一用户资料中登录京东、只保留一个希望用于抢购的购物车标签。任务结束保留浏览器和标签页。复用会话不保证消除平台验证。

添加抢购任务

先从左侧购物车选择一个商品，或粘贴商品链接

使用链接中 SKU 对应的规格，提前打开详情页，到点点击购买。无需先加入或扫描购物车。

购物车任务启动即提前打开页面，开售前60秒复查登录、前30秒预加载；前2秒开始轮询，暂不可勾选时等待放货，勾选核对成功即继续结算。

沿用京东结算页的默认支付方式，不切换通道、银行卡或分期；旧配置的银行卡偏好不再生效。未启用自动付款时，提交订单后由你手动付款。启用后会继续处理已识别的京东收银台；短信、指纹或扫码验证需自行完成。

当前管理服务尚未加载自动付款更新，请关闭旧启动窗口，再运行 start.bat。
